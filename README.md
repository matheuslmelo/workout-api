# Workout API

🚧 Project under development

This project is currently under development. The README will be updated with more information and examples as new features are implemented.

Backend REST API built with Java 17 and Spring Boot, powered by PostgreSQL, focused on managing structured workout plans and progressive overload tracking.

## Stack

- Java
- Spring Boot
- Spring Data JPA
- H2 (dev)
- PostgreSQL (production)

## Running Locally

### Clone the repository

```bash
git clone https://github.com/matheuslmelo/workout-api.git
```

### Navigate to the project directory

```bash
cd workout-api
```
### Run the application

Make sure PostreSQL is running and configured in 'application.properties', the run: 

```bash
mvn spring-boot:run
```
